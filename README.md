# taptch-cs

Standalone, ultra-minimal Coming Soon landing page for Taptch.

## Design Philosophy

- **Aesthetic**: Apple meets Linear — clean, classy, premium, minimal.
- **Rules**: Zero logos, zero icons, zero emojis, zero illustrations, zero images, zero navigation menus, zero decorative animations.
- **Palette**:
  - White: `#FFFFFF`
  - Black: `#101114`
  - Blue: `#1677FF`
  - Subtle grey: `#858B98`
- **Layout**: Single screen (100svh), perfectly balanced across all viewports, zero vertical or horizontal scroll.

## Files

- `index.html` — Semantic, accessible single-viewport HTML structure
- `style.css` — Responsive, modern CSS adhering to the strict minimal palette
- `script.js` — Vanilla JavaScript modal and keyboard accessibility handler
- `README.md` — Project documentation

## Interaction

Clicking **Join the Waitlist** opens a small modal with the message:
> "You're on our radar."

Includes full keyboard accessibility (Escape to dismiss, focus management) and backdrop dismissal.
